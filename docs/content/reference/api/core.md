# Core API

The top level of `frames2py` exports the names below (its `__all__`). The kernel classes are
also exported there; they are documented on the [Kernels](kernels.md) page. The other
public modules are `frames2py.kernels`, `frames2py.publish`, `frames2py.adapters.evt`,
`frames2py.adapters.aedat4`, `frames2py.adapters.hdf5`, `frames2py.recorder`,
`frames2py.viewer` and `frames2py.replay`.
